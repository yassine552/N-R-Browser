# NØR Browser — Bundled New-Tab Backgrounds

All files in this directory (`nor-*.jpg` and `thumbs/nor-*.jpg`) are **original
artworks generated procedurally** for NØR Browser by
`scripts/generate_backgrounds.py` (fractal value noise, layered gaussian
compositing, dithered gradients — deterministic seeds, no source photographs,
no third-party assets, no AI scraping of copyrighted images).

## Notes

- Resolution 1536×864 (16:9), rendered with `background-size: cover`, so both
  1366×768 and larger 16:9 screens are covered without upscaling artifacts.
- Total bundle size ≈ 460 KB for 8 backgrounds + thumbnails (progressive
  JPEG) — sized deliberately so New Tab opens instantly even on integrated
  graphics (Intel HD 520 class) and never touches the network.
- Each background's average luminance decides the page text scheme
  (light text on dark backgrounds, dark text on light ones).
