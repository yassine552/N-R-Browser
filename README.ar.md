# متصفح NØR — README.ar.md

**متصفح NØR** هو متصفح ويب مكتبي مصمَّم على أساس الخصوصية، مبني بلغة C++17
الحديثة وإطار Qt 6.8 / Qt WebEngine (كروميوم). لا يتطلب حسابًا، ولا يحتوي
على أي تتبع أو قياس عن بُعد، ويحفظ جميع بياناتك — التفضيلات والعلامات
المرجعية والسجل والتنزيلات — على جهازك فقط.

تأتي الواجهة باللغة **الإنجليزية (الافتراضية)** و**العربية (بتخطيط من
اليمين إلى اليسار بالكامل)** و**الفرنسية**، مع إمكانية تبديل اللغة أثناء
التشغيل وبنية جاهزة لإضافة لغات جديدة.

| | |
|---|---|
| اسم المنتج | NØR Browser |
| الملف التنفيذي / هدف البناء | `nor-browser` |
| الإصدار | 1.0.0 |
| اللغة البرمجية | C++17 |
| واجهة الرسم | Qt 6.8 Widgets |
| محرك العرض | Qt WebEngine (كروميوم) |
| التخزين | QSettings + SQLite (WAL) |
| المنصات | لينكس (بما فيها PikaOS)، وويندوز 10/11 |

## 1. الميزات

- **هيكل متصفح حديث**: شريط التبويبات أعلى النافذة فوق شريط التنقل،
  وشريط القوائم التقليدي حلّته قائمة واحدة (☰)، وشريط العلامات المرجعية
  لا يظهر إلا عند وجود علامات، وشريط العنوان هو محور شريط التنقل.
- **نظام تصميم موحّد** («جرافيت هادئ ونبضة بنفسجية واحدة»): كل الألوان
  والمقاسات ودرجات الاستدارة توكنات في ‎src/ui/Theme.h‎، وسمتا Dark وLight
  تُولَّدان من قالب QSS واحد. اختر «مطابقة سمة سطح المكتب / داكن / فاتح»
  من الإعدادات. على KDE/X11 مع مدير تأثيرات يظهر Blur حقيقي خلف شريط
  الرأس، وبدونه يبقى المتصفح معتمًا تمامًا (بديل متناسق بلا عيوب بصرية).

### تصفح حقيقي
- عرض HTTP/HTTPS عبر Qt WebEngine (كروميوم).
- تبويبات متعددة مستقلة، تكرار، إغلاق البقية/اليمين، قائمة سياق لكل تبويب،
  واختيار بلوحة المفاتيح (`Ctrl+1..9`).
- لا شريط حالة دائم في النافذة عمدًا: تحتفظ الصفحة بكامل مساحة العرض
  (تظهر روابط التمرير في طبقة عائمة صغيرة لا تستهلك أي مساحة)، وكل صفحة
  تُرسم بلون خلفية السمة، ما يزيل الوميض الأبيض عند تبديل التبويبات.
- تنقّل: رجوع/تقدّم/إعادة تحميل/إيقاف/الصفحة الرئيسية، وشريط تقدم رفيع.
- شريط العنوان: تمييز الرابط عن البحث، دعم الإدخال الدولي (يونيكود/IDN)،
  «اللصق والانتقال»، ومؤشر أمان (قفل للاتصالات الآمنة).
- البحث: **DuckDuckGo هو محرك البحث الافتراضي**؛ مع Google وBing
  وويكيبيديا مُهيّأة مسبقًا، ويمكن إضافة المحركات وتعديلها كليًا من
  الإعدادات ← البحث.
- صفحة تبويب جديدة مخصصة (`nor://newtab`): حقل بحث مع **المواقع الأكثر
  زيارة** — شبكة بأسلوب Firefox تعرض المواقع التي تزورها فعلًا أكثر من
  غيرها، مشتقة من سجل التصفح المحلي بترتيب «frecency» (عدد الزيارات مع
  نصف عمر 14 يومًا)، ومجمّعة ببلاطة واحدة لكل نطاق. التثبيت وإلغاء
  التثبيت والتحرير والإزالة متاحة من قائمة السياق لكل بلاطة، والمواقع
  بلا أيقونة تحصل على بلاطة حرف أنيقة. لا اختصارات ثابتة مدمجة ولا أي
  خدمة خارجية: كل شيء يُحسب من بيانات محلية، ونوافذ التصفح الخاص تعرض
  القائمة للقراءة فقط كي لا تعدّلها جلسة خاصة أبدًا.
- شريط بحث داخل الصفحة مع عدّاد نتائج حي (`Ctrl+F`).
- تكبير/تصغير عبر `Ctrl+/−/0` وعجلة الفأرة مع Ctrl، ويظهر مستوى التكبير
  الحالي كزر صغير بجوار شريط العنوان (النقر عليه يعيد الضبط).
- وضع ملء الشاشة (بطلب من الموقع أو F11).
- إدارة التنزيلات: التقدم والاكتمال والفشل والإلغاء، أسماء ملفات فريدة لا
  تستبدل ملفاتك، فتح بعد الاكتمال، وحوار اختيار الوجهة (أو مجلد افتراضي).
- طبقة «توقفت الصفحة عن الاستجابة» مع زر إعادة تحميل عند انهيار المعالج.

### الخصوصية والأمان
- **بلا حسابات، بلا تتبع، بلا مزامنة سحابية.**
- تصفح خاص حقيقي عبر ملف تعريف WebEngine منفصل تمامًا (off-the-record)
  لا يكتب أبدًا في السجل ويُمحى بالكامل عند إغلاق آخر نافذة خاصة (مُثبَت
  بالاختبارات).
- **حظر الإعلانات والمتتبعات بمحرك [brave/adblock-rust](https://github.com/brave/adblock-rust)
  0.13.5** (رخصة MPL-2.0، مثبّت الإصدار بدقة) عبر محوّل قابل للتبديل، مع
  الإبقاء على محرك C++ المدمج كبديل بلا تبعيات
  (`-DNOR_ADBLOCK_BACKEND=BuiltIn`). دعم كامل لصياغة EasyList/EasyPrivacy:
  قواعد `$domain=` (مع النفي `~`)، و`$match-case` لفلاتر regex، والاستثناءات،
  وصحة النطاقات المسجّلة متعددة الطبقات (مثل co.uk)، و**التصفية الكوسميتية**
  (إخفاء العناصر بمنتقيات CSS عبر سكربتات QtWebEngine المستخدم — CSS فقط،
  ولا تُنفَّذ سكربتلات القوائم إطلاقًا).
- قوائم الفلاتر: تُنزَّل EasyList وEasyPrivacy الرسميتان بطلبات شرطية
  (ETag/304)، وتُتحقق صحتها قبل استبدال النسخة المخبأة (التنزيلات التالفة
  أو صفحات الخطأ تُرفض، ويُعترَف الآن بقواعد EasyPrivacy البسيطة من نمط
  «-tracker.» و«.beacon.min.js»)، وتُخزَّن للعمل دون اتصال، وتُحدَّث تلقائيًا
  في الخلفية (قابل للتعطيل). كاش محرك مُسلسل يجعل الإقلاع يتخطى إعادة
  التحليل (~2 مللي ثانية مقابل ~110 مللي للقائمتين الكاملتين؛ مُقاس).
- إحصاءات حظر لكل موقع في شريط العنوان («N في هذا الموقع · M في هذه
  الجلسة») إلى جانب مؤشر الجلسة الكلي.
- **تحصين الخصوصية (مفعّل افتراضيًا، قابل للتبديل، ومُختبر من الطرف إلى
  الطرف):** رفض كوكيز الطرف الثالث عبر مرشّح مخزن الكوكيز (كوكيز الطرف
  الأول لا تتأثر)، إرسال إشارتَي `DNT: 1` و`Sec-GPC: 1` مع كل طلب، خيار
  كوكيز للجلسة فقط، وكيل مستخدم Chromium موحّد (إزالة وسم بصمة
  `QtWebEngine/x.y`)، وقصر WebRTC على الواجهة العامة الافتراضية (لا كشف
  لعناوين IP المحلية)، وحجب المحتوى غير الآمن داخل صفحات HTTPS، ومنع
  التشغيل التلقائي للوسائط. راجع `docs/PRIVACY.md` لتوضيح صادق لما يُخفَّف
  وما لا يمكن تخفيفه من بصمة المتصفح على هذا المحرك.
- وضع «موفر البيانات» للاتصالات المحدودة: يحجب الصور لكل طلب (كل الصور
  أو صور الطرف الثالث فقط) والجلب الاستباقي وإشعارات ping، مع
  **استثناءات لكل موقع تعمل فعليًا**.
- إكمال تلقائي محلي بحت لشريط العنوان من السجل والعلامات (مطابقة العناوين
  وعناوين URL والمضيفين المزارين؛ يعمل مع العربية والفرنسية؛ لا يرسل
  شيئًا إلى أي جهة؛ قابل للتعطيل).
- أخطاء شهادات TLS **لا تُقبل تلقائيًا أبدًا**؛ القابلة للتجاوز تعرض حوار
  تحذير صريحًا. نقاط HTTPS ذات الشهادات الموقّعة ذاتيًا تُرفض في الاختبارات
  الآلية.
- مطالبات أذونات المواقع (الكاميرا، الميكروفون، الموقع الجغرافي، الشاشة،
  الإشعارات، الحافظة، تثبيت المؤشر، الخطوط المحلية) مع تذكّر لكل موقع
  وواجهة مراجعة (الإعدادات ← الأذونات).
- حوار محو البيانات: السجل وملفات تعريف الارتباط وذاكرة التخزين المؤقت
  فورًا؛ وتخزين المواقع الدائم عند إعادة التشغيل القادمة (لا يُدَّعى
  اكتمال المسح إلا بعد إزالة شجرة التخزين فعليًا — مُختبر بالوحدات).
- حظر انتقالات `file://` التي تبدأها محتويات الويب.
- كل عمليات SQLite تستخدم عبارات مُعدَّة (Parameterized) حصرًا.

### البيانات المحلية
- العلامات المرجعية: إضافة/تعديل/إزالة، شريط علامات قابل للإخفاء، نجمة
  سريعة، مدير حوار، وفتح في التبويب الحالي أو الجديد أو نافذة جديدة.
- السجل: قاعدة SQLite محلية، بحث، حذف انتقائي أو كلي، قائمة «الأحدث»؛
  والنوافذ الخاصة لا تمسه مطلقًا.
- قائمة تنزيلات بالحالات وإعادة الفتح.
- كل المسارات تحترم اصطلاحات نظام التشغيل
  (`~/.local/share/nor-browser` على لينكس،
  `%LOCALAPPDATA%\nor-browser` على ويندوز).

### التعريب
- الإنجليزية افتراضية ومرجعًا عند نقص الترجمة؛ والعربية والفرنسية مترجمان
  بالكامل (221/221 نصًا لكل منهما).
- التبديل أثناء التشغيل من الإعدادات؛ تتبدد الواجهة كلها — القوائم
  والتبويبات والحوارات والتلميحات وصفحة التبويب الجديد — فورًا.
- العربية تحوّل تخطيط التطبيق إلى اليمين-إلى-اليسار، وتنعكس الأزرار
  والتبويبات وشريط العنوان والحوارات بشكل صحيح دون كسر أي وظيفة.
- تنسيق التواريخ والأرقام حسب اللغة.
- انظر `docs/ADD_LANGUAGE.md` لإضافة لغة جديدة.

## 2. البناء على لينكس (ويشمل PikaOS)

### المتطلبات
- GCC ≥ 11 أو Clang ≥ 13 (اختُبر بـ GCC 14.2 على Debian 13)
- CMake ≥ 3.21
- Ninja (موصى به) أو Make
- Qt 6.8.x بالوحدات: Widgets, WebEngineWidgets, WebEngineCore, Sql,
  Network, LinguistTools (lupdate/lrelease), Test
- **اختياري (موصى به): سلسلة أدوات Rust** (عبر rustup، دون صلاحيات جذر)
  لمحرك حظر adblock-rust. بدونها يُبنى المتصفح ويعمل بمحرك C++ المدمج.
  إن لم يكن cargo في `PATH` فوجّه البناء إليه بمتغير البيئة `NOR_CARGO`:

  ```bash
  # تثبيت rustup محليًا للمستخدم (بلا جذر):
  curl -sSf https://sh.rustup.rs | sh -s -- --profile minimal --no-modify-path
  export NOR_CARGO=~/.cargo/bin/cargo   # أو أينما وضع rustup الأداة
  ```
- مكتبات النظام (أسماء حزم Debian/Ubuntu):
  `libnss3 libasound2t64 libxkbcommon0 libxkbcommon-x11-0 libxcomposite1
  libxdamage1 libxrandr2 libgbm1 libatspi2.0-0 libcups2 libxtst6
  libxcb-cursor0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1
  libxcb-render-util0 libxcb-util1 libxcb-xkb1 libegl1 libopengl0
  libgl1`

على Debian/Ubuntu أسهل طريق هو حزم النظام:

```bash
sudo apt install qt6-webengine-dev qt6-webengine-dev-tools \
     qt6-tools-dev qt6-tools-dev-tools libqt6sql6-sqlite \
     cmake ninja-build g++
```

أو عبر مثبّت Qt الرسمي (أي إصدار Qt ≥ 6.8.0، GCC 64-bit).

### التهيئة والبناء والاختبار والتشغيل

```bash
cd nor-browser
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
      -DCMAKE_PREFIX_PATH=/path/to/Qt/6.8.x/gcc_64
cmake --build build -j

# اختبارات الوحدة (Qt Test عبر CTest)
ctest --test-dir build --output-on-failure

# التشغيل
./build/nor-browser                 # نافذة عادية
./build/nor-browser --private       # نافذة خاصة
./build/nor-browser https://example.org
```

يدمج البناء الترجمات والموارد داخل الملف التنفيذي.

### الاختبارات المعيارية (من الطرف إلى الطرف)

```bash
tests/scripts/run_smoke_tests.sh build   # يشغّل الخادم المحلي وXvfb تلقائيًا
```

يغطي الجناح: تحميل صفحات حقيقية من خادم محلي، التنقل متعدد التبويبات
رجوعًا وتقدمًا، دلالات شريط العنوان (رابط مقابل بحث واستعلام عربي)، فصل
ملف التعريف الخاص وتنظيفه، تبديل EN→AR→FR مع التحقق من RTL (مع فحص أن
صفحة التبويب الجديد تعرض محتواها فعلًا)، تنزيلًا حقيقيًا (تقدمًا ومحتوى
وأسماء فريدة)، **التصفية الكوسميتية على صفحة حقيقية** (إثبات إخفاء عناصر
الإعلانات وسلامة المحتوى)، **حجب عناوين URL لمتتبعين حقيقيين**
(doubleclick وGoogle Analytics/Tag Manager وScorecardResearch) مع تحميل
قائمتَي EasyList وEasyPrivacy الحقيقيتين — على مستوى المحرك وعبر المُعترِض
الحقيقي في الشبكة، **تحصين الخصوصية** (ترويستا DNT/GPC كما استلمهما الخادم،
ووكيل المستخدم الموحّد، وحجب كوكيز الطرف الثالث مع شهادة تحكم لكوكيز
الطرف الأول)، **رفض شهادات TLS غير الصالحة** (نقطة HTTPS موقّعة ذاتيًا
تفشل بينما HTTPS السليم يُحمَّل)، وموقع HTTPS حقيقيًا (https://example.com).

> في الحاويات المقيّدة لا يستطيع كروميوم تشغيل آلية العزل (لا توجد
> User Namespaces)، لذا يضبط مشغّل الاختبارات
> `QTWEBENGINE_DISABLE_SANDBOX=1` **لبيئة الاختبار فقط** — المتصفح نفسه
> لا يعطّل آلية العزل مطلقًا.

### التثبيت (اختياري، على مستوى المستخدم)

```bash
./packaging/linux/install.sh            # يثبّت في ~/.local
# أو على مستوى النظام بقواعد التثبيت المولدة:
cmake --install build                   # /usr/local افتراضيًا (بحقوق root)
```

## 4. تخطيط المشروع

```
nor-browser/
├── CMakeLists.txt               # البناء + التثبيت + تسجيل الاختبارات
├── src/
│   ├── main.cpp                 # تسجيل المخطط، سطر الأوامر، الإقلاع
│   ├── core/                    # AppConfig، LanguageManager، SearchEngines،
│   │                            # BookmarkStore، HistoryStore،
│   │                            # DownloadManager، Paths
│   ├── privacy/                 # FilterRule، AdBlockClient،
│   │                            # RequestInterceptor
│   ├── browser/                 # ProfileManager، WebPage، WebView،
│   │                            # TabWidget، AddressBar، FindBar،
│   │                            # NewTabSchemeHandler، BrowserWindow،
│   │                            # BrowserApplication
│   └── ui/                      # Theme، IconProvider، حوارات
│                                # الإعدادات/السجل/العلامات/التنزيلات/
│                                # مسح البيانات
├── resources/                   # سمة QSS، أيقونات SVG، HTML صفحة
│                                # التبويب الجديد، قائمة الحظر المدمجة،
│                                # خطوط عربية
├── translations/                # en / ar / fr (‏.ts + ‏.qm مولدة)
├── tests/                       # 4 أجنحة Qt-Test + سكربتات الدخان
│                                # + خادم الاختبار
├── packaging/                   # ملف desktop وأيقونات لينكس وسكربت
│                                # التثبيت، و‏.rc وأيقونة ويندوز
├── docs/                        # FILTER_RULES، PRIVACY، ADD_LANGUAGE،
│                                # WINDOWS_BUILD، DEPENDENCIES
└── scripts/                     # توليد الأيقونات وملء الترجمات
```

### ملاحظات معمارية
- `ProfileManager` هو المالك **الوحيد** لملفي تعريف WebEngine (الدائم
  العادي والخاص off-the-record). المعترضات ومعالجات المخطط أبناء لملف
  التعريف نفسه، فلا يمكن أن يعلّقوا بعده.
- ترتيب الحذف صريح: النوافذ (ثم الصفحات) أولًا، وملفات التعريف ثانيًا.
- `WebPage` يجمّع سياسات الصفحة: الشهادات، الأذونات، النوافذ المنبثقة،
  مصادقة HTTP، وتسجيل السجل.
- محرك الخصوصية (`FilterRule`/`AdBlockClient`) خالص لـ QtCore ويُختبر
  وحدويًا دون WebEngine.

## 5. اختصارات لوحة المفاتيح

| الإجراء | الاختصار |
|---|---|
| تبويب جديد / إغلاق التبويب | `Ctrl+T` / `Ctrl+W` |
| نافذة جديدة / خاصة | `Ctrl+N` / `Ctrl+Shift+P` |
| تكرار التبويب | `Ctrl+Shift+K` |
| اختيار تبويب 1–8 / الأخير | `Ctrl+1..8` / `Ctrl+9` |
| التركيز على شريط العنوان | `Ctrl+L` |
| البحث في الصفحة | `Ctrl+F` |
| وضع علامة مرجعية | `Ctrl+D` |
| السجل / التنزيلات | `Ctrl+H` / `Ctrl+J` |
| التكبير | `Ctrl+Plus / − / 0`، عجلة الفأرة مع Ctrl |
| رجوع / تقدّم | `Alt+Left` / `Alt+Right` |
