# Dependencies and Licenses (docs/DEPENDENCIES.md)

NØR Browser is deliberately thin: one framework, one database engine,
and (optionally, by default) one native ad-blocking engine — no
third-party application libraries beyond that.

NØR Browser itself is free software under the **GNU General Public
License v3.0 or later** (`GPL-3.0-or-later`, see `LICENSE`). The table
below lists the license options *offered by each dependency's
upstream* — this project does not relicense any of them.

The full redistributable-license inventory, including every transitive
Rust dependency resolved by Cargo, lives in **`THIRD_PARTY_NOTICES.md`**
(regenerated with `scripts/gen_third_party_notices.py` from
`adblock-sys/Cargo.lock` + the local cargo registry cache).

## Downloaded at runtime (never compiled in)

EasyList and EasyPrivacy are fetched from easylist.to with conditional
requests, validated, cached in the user's profile and auto-updated.
They are the work of their own authors and remain under their own
terms — the EasyList repository contents are dual-licensed
**GPL-3.0-or-later OR CC-BY-SA-3.0-or-later**, with attribution to
"The EasyList authors (https://easylist.to/)"; EasyPrivacy is hosted by
the same project but the licence page notes that externally-hosted
files may carry their own conditions. Offline test snapshots are
redistributed as `tests/fixtures/filterlists/` for the automated test
suite under those same upstream terms (see THIRD_PARTY_NOTICES.md).

## Development-environment extras (not part of the shipped app)

The CI container used to develop and test this version also fetched,
without root, into a local toolchain directory: Qt 6.8.2 binaries via
aqtinstall (MIT), CMake/Ninja wheels from PyPI (as above), Pillow
(MIT-CMU) + NumPy (BSD-3-Clause) for icon rasterization and the
procedural background generator (`scripts/generate_backgrounds.py`),
and Debian dev/runtime `.deb`s
extracted locally for GL/XKB/XCB/EGL headers. None of these are
required on a normal development machine with Qt installed.
